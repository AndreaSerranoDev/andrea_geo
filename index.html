SURFACE PROFILE BASE

Know the assumptions

Homogeneous, horizontal layers with small-strain shear-wave velocities. Travel time is Σ(h/Vs); average Vs is H/Σ(h/Vs). Vs30 uses only the upper 30 m and is unavailable for shallower profiles. Gmax = ρVs².

The estimate T ≈ 4Σ(h/Vs) is a quarter-wave approximation assuming a strong impedance contrast at the profile base. It is not a validated site-response analysis or a design result. No seismic site class is assigned.
